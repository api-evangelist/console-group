# Console Group

> Australian property management and trust accounting software company, founded 1992 in Brisbane. Console Cloud (rebranded Reapit PM after the Reapit acquisition) is the system of record for the rent roll, the trust account and the tenancy for thousands of residential and commercial agencies across Australia and New Zealand. Console Group publishes NO public API: no developer portal, no API reference, no OpenAPI/Swagger/GraphQL/AsyncAPI document, no SDK, no webhooks documentation and no partner developer programme. A private integration API demonstrably exists — a live marketplace lists ~21 two-way third-party integrations — but access is by commercial arrangement only and nothing about it is published.

## APIs

- No public API. https://api.console.com.au/ resolves and answers as a Kong API Gateway ("no Route matched with those values") but exposes no anonymous route, no spec and no GraphQL endpoint.
- No /.well-known/ discovery document on any host (security.txt, openid-configuration, oauth-authorization-server, api-catalog, ai-plugin.json all 404).
- Australia has no MLS, so there is no RESO Web API or Data Dictionary certification, no OData $metadata and no Universal Property Identifier anywhere in the stack.

## Products

- [Console Cloud / Reapit PM](https://www.console.com.au/cloud): property management and trust accounting.
- [Console Go + Inspect](https://www.console.com.au/features/console-go-inspect): mobile inspections and maintenance.
- [Maintenance](https://www.console.com.au/features/maintenance): maintenance workflow.
- [Console Pay](https://www.console.com.au/features/console-pay): rent and one-off payment collection.
- [Commercial](https://www.console.com.au/features/commercial): commercial property management.
- [Analytics+](https://www.console.com.au/features/analytics): reporting and business intelligence.
- [Owner Portal / Tenant App](https://www.console.com.au/features/owner-portal): owner and tenant experience.
- [Console SMS](https://www.console.com.au/features/sms): agency communications.
- [Console Sales / Reapit Sales](https://www.console.com.au/features/console-sales): sales CRM sibling product.
